# PLEASE DO NOT THROW RICHIE

An irresponsible Devoxx physics game.

Richie has a keynote. Richie has no legs. Get him from registration to the keynote stage using hops, Voxxy, Droid, Biggy and the audience.

## Run

Install with `npm ci`, start with `npm run dev`, then open the URL shown by Vite. The game is client-side and needs no backend or physical robot.

Controls: WASD aims, Space charges and hops, mouse drag orbits, E activates a nearby assist, and R resets to the checkpoint.

Verify with `npm test` and `npm run build`. The generated `dist/` folder works on a static host.
